帮我写一个python程序 静电场描绘实验 程序界面分为左右两块 
在界面顶部放置一个选项卡（按钮组）在 无限长带电直导线的静电场 和 无限长带电直同轴电缆的静电场 中二选一
选择无限长带电直导线的静电场时（选择其它选项的功能待定）

左侧区域为“实验装置区域”
从程序目录的background文件夹 导入图片“导电玻璃2.jpg”

下方放置按钮组“移动探针” “描绘曲线” “擦除曲线” 选一 

在左侧区域的图片上（以图片为背景叠加在图片上）放置探针  选择移动探针时可用鼠标长按拖动探针移动位置

选择描绘曲线时可用鼠标在背景图片上画线

选择擦除曲线鼠标变为橡皮擦可清除线

下方放置按钮“导出曲线”可导出绘制的曲线截图
“清空曲线” 可清除绘制的所有线

右测区域为“实验主机区域”
导入图片 “主机.jpg" 
把图片作为背景放置一个电压显示框（叠加在图片上）

图片下方（不叠加在图上）放置电压调节进度条 带+-微调按钮精度0.01V 范围0-15V
进度条下方放置按钮 输出/测量  初始按钮显示输出 点击后切换（在输出和测量之间切换）
选择输出时 电压调节进度条可用 在电压显示框上显示进度条的电压值 
选择测量时 在左侧区域背景图上模拟无限长带电直导线的静电场 根据探针的位置显示电压


获取程序目录用下面这个函数
def get_resource_path(relative_path):
    """获取资源的绝对路径，支持打包后的环境"""
    try:
        # 打包后的临时文件夹路径
        base_path = sys._MEIPASS
    except Exception:
        # 开发环境的路径
        base_path = os.path.dirname(os.path.abspath(__file__))
    
    return os.path.join(base_path, relative_path)
