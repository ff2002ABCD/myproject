# FD-BH-C 静态磁滞回线测量实验仪

## 项目概述

FD-BH-C 是用于测量铁磁材料磁滞回线特性的实验仪器，通过控制励磁电流产生变化的磁场，记录材料的磁化曲线和磁滞回线。

## 显示格式说明

### 电流显示 (LCD_Current)
- **量程**: 0-600.0 mA
- **显示格式**: 5位数字，用0填充
  - 0-9.9 mA: `000.0` 格式
  - 10-99.9 mA: `0XX.X` 格式
  - 100-600.0 mA: `XXX.X` 格式

### 磁场显示 (LCD_Tesla)
- **量程**: 0-2.000 T
- **分辨率**: 0.1 mT
- **显示格式**: 5位数字，四位半LED显示，用0填充
  - 0-0.9 T: `000.0` 格式
  - 1.0-9.9 T: `00X.X` 格式
- **方向控制**: Direction按钮只影响磁场的正负显示，0值不显示负号

## 文件说明

- `run_bhc.py` - 主程序启动器

- `test_display.py` - 显示格式测试脚本

## 使用方法

### 运行主程序
```bash
python run_bhc.py
```

### 运行演示程序
```bash
python demo_display.py
```

### 运行测试
```bash
python test_display.py
```

## 控制说明

- **电流旋钮 (Knob_Current)**: 控制0-600.0mA励磁电流
- **磁场旋钮 (Knob_Tesla)**: 控制0-2.000T磁场显示
- **电源开关 (PowerSwitch)**: 开启/关闭仪器
- **方向切换 (DirectionToggle)**: 切换磁场方向（正/负）

## 显示逻辑

显示格式严格按照仪器规格实现：
- 所有显示都用前导0填充，确保显示长度一致
- 磁场方向只通过正负号显示，不改变数值
- 零值不显示负号

## 技术规格

- **电流控制**: 0-600.0mA 连续可调
- **磁场测量**: 0-2.000T，分辨率0.1mT
- **显示类型**: 四位半LED显示
- **界面**: PyQt5 GUI

1. 确保Python环境已安装PyQt5
